# CoDE-Stop：租GPU与调用API的完整预算口径

核验日期：2026-09-21。币种除明确标为美元外均为人民币。未启动GPU、未下载权重、未调用付费推理。本表替代此前把所有模型/基准统一按5–20次探测估计的默认规划；旧表仍是有效的假设情景，并非实测费用。

## 1. 决策与范围

**维持论文原检查点、BF16精度的首轮研究，优先考虑单卡自行部署；原Qwen3-4B和DeepSeek-R1-Distill-Llama-8B尚未核实兼容的按token服务报价。** 不据此声称所有供应商都没有这两个模型。DeepInfra Qwen3-14B有公开价格，但为FP8，属于需要单独说明和校准的部署版本。

建议先把Qwen3-4B/MATH500阶段的可用资金控制在300元内，其中先用10–20元诊断运行能力与端到端时间。300元是阶段支出额度，不是完成保证；当前没有实测可据以承诺总GPU小时。诊断后再确定是否扩至DeepSeek8B。本次预算并不授权或启动付费任务。

各预算行均只覆盖Vanilla、DEER、CoDE三方法，一份基础轨迹共用，不是为三方法分别生成三份完整推理。

| 范围 | 基础轨迹数 | 尚不包含 |
| --- | ---: | --- |
| 一个模型、MATH500 | 1,000 | 其他基准、其他强基线、消融 |
| Qwen4B+DeepSeek8B、MATH500 | 2,000 | 同上 |
| 两模型、四主要基准 | 8,418 | 其他强基线、提示变体、16K实验及全部消融 |
| 四模型、四主要基准 | 16,836 | 同上，仍不是全文复现 |

AMC23重新校准另有80条基础轨迹/模型；其完整推理长度、参数搜索开销没有足够公开数据，本表作为单独预留项，而不冒充已精确计价。来源：[论文实验设置与附录](https://arxiv.org/html/2604.04930v2)。

## 2. 租GPU：已知单价和可购买时长

AutoDL普通按量实例的公开参考价如下，实际选机页价格、库存与配套CPU/RAM需在开机前核对。时间列是**总计费卡时的费用情景，不是预计完成时间**，不能认为不同卡在同样时间内完成同样工作。

| 单卡 | 显存 | 元/卡时 | 10小时 | 30小时 | 60小时 | 100小时 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| RTX5090 | 32GB | 2.78 | 27.80 | 83.40 | 166.80 | 278.00 |
| A800 | 80GB | 5.59 | 55.90 | 167.70 | 335.40 | 559.00 |
| RTX PRO6000 | 96GB | 6.98 | 69.80 | 209.40 | 418.80 | 698.00 |
| H800 | 80GB | 9.98 | 99.80 | 299.40 | 598.80 | 998.00 |

来源：[AutoDL官方首页](https://www.autodl.com/home)。不采用历史48GB报价或最低起价优惠作为确定可购价格。

- Qwen4B可先测试5090 32GB；不保证原样长前缀实现的峰值显存必定通过。24GB卡不能仅因权重能装下就视为适合32K全协议。
- 两模型可顺序运行，不需要同时租两张卡。DeepSeek8B的32GB仍需测，48GB更有余量但本次无可靠实时租价；80GB是较宽裕的候选。
- 四模型也可顺序运行，14B优先考察48/80GB。是否统一租80GB更便宜，必须比较实际耗时。
- 额外显存不等于更低总费用；目前不能声称5090或A800是全市场最经济的最终方案。

完整计价：

```text
GPU路线总费用 = 各卡时租×各自总开机小时之和 + 磁盘费用 + 判分API费用
阶段规划额度 = 上述已估费用 + 明确留出的重跑与异常余量
```

总开机小时必须包含准备/加载、基础生成、强制补答、两种停止方法探测及补答、长前缀计算、缓存搬运和GPU开机期间的等待。不能只用输出token除以解码速度估算。

例如，假定一阶段全流程实际需要40小时5090，则租费111.20元；再留30%重跑余量33.36元和判分/磁盘20元，合计164.56元。**40小时只展示算式，尚无证据证明能在该时间内完成指定复现。**

推荐测速后采用：`总小时 = [准备/加载秒数 + Σ(各基准轨迹数 × 该基准实测单轨迹全流程平均秒数)] / 3600`。分别采样不同模型、不同基准和长尾题，不能用MATH500乘4.209代替四基准实测。

## 4. 用论文步数修订API工作量

采用表1的逐基准平均完整输出长度和表3的全轨迹平均检查步数，分别计算再相加。MATH500中Qwen4B平均5.4步、DeepSeek8B平均22.3步；DeepSeek8B在AIME、GPQA分别约98.8、70.4步，统一K=5–20会低估这些全轨迹采集情景。

计算器：[estimate_paper_budget.py](../scripts/estimate_paper_budget.py)。假设题目/模板500token、每次重复前缀取该基准平均推理长度的一半、试答21token；默认两个策略各自采集一轮完整探测，两方法各留30token最终答案，并为每条基础轨迹额外预留一次30token强制补答。不计供应商缓存折扣。

**这是全轨迹采集的费用情景，不是原代码实际早停账单、在线加速比或费用上界。** 原方法会提前停探；相同试答经一致性验证后可以共享，进一步省费，但项目尚未实现共享探测缓存。另一方面，长轨迹与多探测可能相关，均值乘积不等于真实逐请求前缀总量，费用也可能超过本表。原强制补答仅对接近token上限的轨迹触发，长度并非固定30；30token只是可替换的预算假设。

为了在未找到服务前仍能规划规模，明确设置两个**假设单价，不是供应商报价**：输入/输出分别为¥0.5/¥2和¥1/¥3，每百万token。四模型情景也只是给每个模型套同一档单价，不能称四模型已有可购API。

| 范围 | 低价假设：主实验token费 | 较高价假设：主实验token费 | 含额外预留的规划资金 |
| --- | ---: | ---: | ---: |
| Qwen4B / MATH500 | 34.17 | 62.81 | 110–150 |
| DeepSeek8B / MATH500 | 79.43 | 153.26 | 170–280 |
| 两模型 / MATH500 | 113.60 | 216.07 | **250–400** |
| 两模型 / 四主要基准 | 1,538.12 | 3,004.50 | **2,500–4,700** |
| 四模型 / 四主要基准 | 2,048.94 | 3,971.34 | **3,300–6,200** |

主实验token费由未舍入输入/输出计算，合计可因分项四舍五入相差一分。规划资金用`1.5×主实验费+固定预留`向上取整：MATH500固定50元、两模型四基准100元、四模型四基准150元。加成中的20%用于AMC校准/参数准备预留，30%用于重试、前缀与长度偏差；固定预留用于接口诊断、判分及支付汇差。**比例是资金分配建议，不是这些额外项的实测价格或上限**，尤其不能保证覆盖长尾或更换判分协议。

双模型MATH500总输入约182.679百万、总输出11.1294百万token；四基准约2,789.290百万输入、71.738百万输出。重复输入量解释了四基准API费用为何可能明显高于此前粗估。默认情景两模型MATH500约63,400次请求（不含判分/重试）；限流与网络延迟会影响工期。

有真实价格的单独候选：DeepInfra Qwen14B，按$1=¥7.2的**预算汇率**（非实时结算汇率）及相同论文步数假设，MATH500约46.28元、四基准约443.29元纯token；按上述预留分别约120–150元、800元。FP8服务的生成长度、探测数可能与论文BF16不同，因此这些仍是推算，不能与4B租卡直接作对等价格比较，也不能当论文BF16结果。

## 5. 两路线都要计入的费用

| 项目 | 租GPU | Mac运行脚本+API |
| --- | --- | --- |
| 模型权重/开源代码 | 无购买费 | 无权重购买费，也不必下载权重 |
| 训练 | 本次为免训练方法，0 | 0 |
| 准备、加载、基础生成、探测、校准 | 都消耗开机时间 | 成功计费请求消耗输入/输出token；校准单列预留 |
| 判分 | 少量API费；见下方 | 同样需要判分费 |

官方实现的MATH500/GSM8K默认GPT-4o-mini判分，AIME使用符号验证，GPQA使用选项提取。判分单价每百万输入$0.15、输出$0.60；每次假设500输入/最多5输出token、不计缓存折扣，约¥0.0005616/次。计base、forceans、DEER、CoDE各一次时：一个模型MATH500约4,000次/2.25元；两模型约4.49元；两模型四基准（仅MATH/GSM付费判分）约10.42元。可初步给两模型MATH判分留10元、四基准留20元，若提取失败传入长文本、反复判分或增加基线则需重算。不能为了省这笔钱而无说明地改评价协议。

来源：[固定代码判分入口](https://github.com/sudoparsa/CoDE-Stop/blob/b5081e7c2abe23bb1d19649421cc13522fee7c50/inference.py)、[判分请求实现](https://github.com/sudoparsa/CoDE-Stop/blob/b5081e7c2abe23bb1d19649421cc13522fee7c50/llm_eval.py)、[OpenAI官方GPT-4o-mini价格](https://developers.openai.com/api/docs/models/gpt-4o-mini)。这里是短答案token假设，不是实测usage。

AutoDL普通实例若首轮4B在免费50GB数据盘内可用，额外磁盘费为0。双模型推荐60–80GB可用、四模型120–150GB可用，但逐个运行后删除可重新下载的权重可减少常驻存储。**本地扩容盘的单价以每台主机为准，不能把独立文件存储0.01元/GB/日当作扩容单价。** 若自愿选独立文件存储保留80GB共14天，按免费20GB后计费为8.40元；150GB共14天为18.20元，不与未购买的其他存储重复相加。

按量GPU开关机时间精确到秒，整点是扣费时机；无需为了“凑满一小时”让GPU空转。付费磁盘即使关机仍可能按日计费。以上均据[AutoDL官方计费说明](https://api.autodl.com/docs/price/)，特定实例若有特殊套餐则另按结算页核对。

本预算未包含现有电脑折旧、普通网络/电费、人工、购置新电脑、后续训练方法或全文所有额外基线/消融。全文尚不能给可信固定总价；四模型四基准三方法不能称为全文完成。

## 6. 使用这张表

1. 先选原4B/MATH500，准备300元阶段额度，第一笔诊断以10–20元为限；当前不因本预算自动开机。
2. 测到短、中、长轨迹全流程耗时和显存后，把租卡表中的假设小时换成外推值，并留下长尾余量。
3. 若原模型API有明确供应商，再验证协议，记录真实usage，用同模型/精度/方法范围比较。没有兼容报价前不按假设API表充值。
4. 保存完整推理与试答缓存，能在本地复算的阈值不重复付费；新增试答位置或在线测速另计成本。

截至核验日可以确认租价、公开API单价、模型文件大小与算术，不能确认最低完工费用。以一小批真实运行把预算从“情景”变成“测算”，比继续为未知吞吐指定精确总价更可靠。

离线复算示例（只打印JSON，不联网或推理）：

```bash
python3 scripts/estimate_paper_budget.py \
  --models qwen3-4b deepseek-r1-distill-llama-8b \
  --scope math500 --input-price-cny 0.5 --output-price-cny 2
```

切换`--scope main4`得到四基准；将价格改为1和3得到较高价假设。只有找到并验证具体服务后，才应替换为供应商实际价格。
